# Andrea — Pedidos

Primera versión de una aplicación para registrar pedidos de prendas, bordados, inventario y proformas.

La carpeta está preparada para un repositorio privado de GitHub y para publicación automática en GitHub Pages. Lee [SUBIR-A-GITHUB.md](SUBIR-A-GITHUB.md) antes de publicar.

## Abrir la aplicación

1. Abre `iniciar-andrea.cmd` con doble clic.
2. En el navegador, entra a `http://localhost:4173` si no se abre automáticamente.
3. Para instalarla en un celular, publica esta carpeta en un hosting con HTTPS y entra desde Chrome o Safari. Después usa la opción de instalar o añadir a pantalla de inicio.

## Lo que incluye

- Pedidos de camisetas, pantalones, conjuntos de calentador y suéteres de lana.
- Entrada manual y dictado por voz en Chrome o Edge (requiere permiso de micrófono).
- Detalles de bordado: diseño, posición, colores del hilo y costo.
- Registro de anticipos, saldo y estado de producción.
- Inventario de prendas terminadas.
- Proformas/recibos imprimibles o guardables como PDF.

## Nota importante

Los datos se guardan localmente en el navegador de cada dispositivo. Esta versión es una primera app funcional, no una plataforma multiusuario todavía. Para que celular y computador compartan pedidos, el siguiente paso es conectar una base de datos en la nube y crear cuentas para las personas que atienden.

La proforma no es una factura tributaria del SRI. La facturación electrónica puede añadirse más adelante.
